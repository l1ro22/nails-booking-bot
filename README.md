# Бот для записи на маникюр 💅

Telegram-бот, который принимает заявки клиентов и отправляет их мастеру.

## Возможности
- Меню услуг с ценами на инлайн-кнопках
- Пошаговая анкета: услуга, удобное время, имя, телефон
- Отправка телефона одной кнопкой
- Мгновенная отправка заявки мастеру
- Отмена записи командой /cancel

## Технологии
Python, aiogram 3, FSM, python-dotenv

## Запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_ID`
3. Запустите: `python nails.py`
